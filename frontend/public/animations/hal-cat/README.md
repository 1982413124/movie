# HAL CINEMA 猫のLottie

いただいた透過PNGを組み合わせた、管理者ログイン画面用のアニメーションです。PNGの絵柄はそのまま埋め込み、Lottieのマスクとキーフレームで動かしています。

## 開き方

`HAL-CINEMA-cat-preview.html` をブラウザで開くと、ネット接続なしで試せます。カーソルを左右に動かすと猫が歩き、止まると座ります。パスワード欄にフォーカスすると目を閉じます。「ログイン成功の演出を見る」でジャンプを確認できます。確認ページは入力内容を送信せず、認証も行いません。

`HAL-CINEMA-cat-lottie.json` は画像を埋め込んだLottie JSONです。外部画像フォルダは不要です。単独で再生すると、各動作を順に再生します。

## 収録した動き

| マーカー | フレーム（終了は含まない） | 動き |
| --- | --- | --- |
| idle | 0–240 | お座り、呼吸、瞬き、耳とヒゲの小さな動き、尻尾の揺れ |
| walk | 240–264 | 足を交互に動かす歩行ループ |
| sit | 264–282 | 移動後に腰を下ろす動き |
| privacy | 282–342 | パスワード入力中に目を閉じる |
| success | 342–402 | 笑った目、2回のジャンプ、尻尾の振り、星のきらめき |

512×512、30fps、背景透過。元のPNGを使ったLottieのため、全てがベクターのアニメーションではありません。

カーソルの位置やログイン結果はLottie JSONだけでは受け取れません。同梱の `hal-cat-controller.ts` が横移動と動作の切り替えを担当します。`setMood("privacy")`、`setMood("success")`、`setMood("idle")` で状態を変えられます。

## HAL CINEMAへの組み込み

既存の `frontend/app/admin/login/page.tsx` に反映済みです。フォーム上部に猫を配置し、紺のリボンに合わせたボタンと淡い背景にしました。認証APIの成功応答を受けてから成功演出を始め、通常は約2.1秒後に `/admin/movies` へ移動します。成功前の遷移や重複送信を防ぎます。APIやDBの変更はありません。

動きを減らす設定では静止した成功ポーズとメッセージを表示し、約0.45秒後に進みます。一時停止ボタンもあります。ページが非表示になったときは再生を止め、離れるとイベントとLottieを破棄します。Lottieを読み込めない場合は静止画を表示し、フォームは使えます。

同梱の `frontend/` は組み込み用ファイルです。`source/build-cat.cjs` は元のPNGからJSONを組み立てるスクリプトです。引数にPNGフォルダを渡すと、隣の `build/` に書き出します。

```powershell
node source/build-cat.cjs "C:\path\to\猫用"
```

`build-preview.cjs` と `capture-rig.cjs` は制作時のスクリプトです。確認ページは完成済みのHTMLをそのまま使えます。

## 確認

- Next.js本番ビルド、TypeScript、変更部分のESLint。
- カーソル追従、停止後のお座り、パスワード欄での反応、一時停止。
- ログイン失敗時のエラー表示と再試行、成功時の演出と遷移、重複送信防止。
- 390pxのタッチ画面、動きを減らす設定、アニメーション読み込み失敗時の静止画。
- オフラインのHTMLで再生と成功演出。

ログイン成功・失敗の確認は、隔離したブラウザで認証APIの応答を差し替えて実施しました。実アカウントを使うログイン確認やDBへの書き込みは行っていません。

axeの自動検査は違反0件です。グラデーション背景のヘッダーとフッターは自動判定の対象外だったため、背景色の範囲を使って文字のコントラストを別途確認しました。
