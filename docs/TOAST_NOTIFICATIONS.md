# トースト通知

3000側の共通レイアウトで `ToastViewport` を表示する。画面遷移で消えず、成功は4.5秒、エラー・注意は9秒で閉じる。ホバー、キーボードフォーカス、タブ非表示中はタイマーを止める。同じ内容の重複はまとめ、最大3件を表示する。

操作の成功が確定した後に通知する。ページ表示時やクリックしただけの時点では成功通知を出さない。

```ts
import { toast } from '@/lib/toast-store.mjs';

toast.event('reservation.completed');
toast.error('保存できませんでした。もう一度お試しください。');
```

既存の予約確定、キャンセル、会員情報の保存、管理画面の映画・上映回操作、入力・通信エラーに接続済み。会員情報保存の対象は既存実装と同じブラウザ内の情報で、今回サーバーへの更新APIは追加していない。

クーポン・お気に入りは機能本体が未実装のため、次の呼び出し口だけを用意している。機能を追加した際に、実際の結果を確認してから呼び出す。

```ts
toast.event('coupon.applied');
toast.event('coupon.failed', { message: 'このクーポンは期限切れです。' });
toast.event('favorite.added');
```

通知はメモリ内だけで保持する。再読み込み時に古い成功通知は復元しない。通知以外のフォーム内エラーや予約完了の詳細表示は、そのまま残している。
